# FP16／BF16 三機能共有の一次方式

exp、reciprocal、rsqrtを、区分一次近似と共通の乗算・加算・出力処理で実装する試作です。
一つのRTLでFP16とBF16を扱い、入力信号 `is_bf16` で形式を実行時に切り替えます。
`is_bf16=0` はFP16、`is_bf16=1` はBF16です。既存のFP32演算器は変更しません。

## 暫定仕様

| 項目 | FP16 | BF16 |
|---|---|---|
| 符号／指数／fraction | 1／5／10 bit | 1／8／7 bit |
| 指数bias | 15 | 127 |
| 関数 | exp(x)、1/x、1/sqrt(x) | 同左 |
| 誤差 | normal参照結果から最大1 RNE step。faithfulは要求しない | 同左 |
| 単調性 | expは非減少、recipは正負を分けて非増加、rsqrtは正領域で非増加 | 同左 |
| subnormal | 入力は符号付きzero、出力は対象形式へRNEした後に符号付きzeroへflush | 同左 |

NaNはcanonical quiet NaNとします。exp(±0)=1、exp(+Inf)=+Inf、exp(-Inf)=+0です。
recip(±0)=±Inf、recip(±Inf)=±0です。rsqrt(±0)=±Inf、rsqrt(+Inf)=+0、
負のnormal入力と-InfはNaNです。FTZとoverflowの結果分類も参照値と一致させます。
normal同士の1 step以内という条件だけで、zeroやInfへの誤った遷移を許容しません。

## 基本的な考え方

まず指数による倍率と、実際に近似する部分を分けます。
recipは `x=2^e*m` とすると `1/x=2^(-e)*(1/m)` なので、指数の符号を反転し、
`1<=m<2` の仮数部分だけを近似します。rsqrtは指数の偶奇 `p=e mod 2` を分離し、
`1/sqrt(x)=2^(-floor(e/2))/sqrt(2^p*m)` とします。
expは `z=x*log2(e)` を整数部と小数部に分け、`exp(x)=2^floor(z)*2^frac(z)` とします。

次に、近似する区間を小さく分け、区間中心との差 `d` と係数 `c0,c1` を選びます。
三関数とも `y=c0+RNE(d*c1)` の同じカーネルを通し、最後に指数による倍率を復元します。
同じ形式の三関数では係数の小数bit数と積の丸め位置を揃え、形式間ではその位置を切り替えて、
近似用の乗算器を一つに共有します。

| 形式・数値モデル | exp／recip／rsqrt表要素数 | d・c0／c1の小数bit数 | 形式ごとの必要乗算幅 |
|---|---|---|---|
| FP16・fp16 | 16／16／32 | 13／9 | signed 9×11 |
| BF16・bf16 | 4／8／8 | 9／5 | signed 7×7 |

上表の乗算幅は形式ごとに必要な幅です。実際のRTLはsigned 9×11の乗算器を一つだけ持ち、
BF16の残差・係数を符号拡張して入力します。積のRNE位置はFP16で9 bit、BF16で5 bit切り捨てへ
切り替え、c0加算と出力丸め・指数復元も共有します。係数表は形式・関数別です。

rsqrtの表要素数は指数偶奇を合わせた総数です。二つの補間節点から係数を生成し、
係数量子化、積の整数RNE、指数復元、出力丸めまで含めて誤差を検査します。
recipの仮数1、rsqrtの仮数1かつ偶数指数は厳密値を返す別経路を持ちます。

expの初段は入力仮数へQ14の定数 `23637=round(log2(e)*2^14)` を掛けます。
BF16仮数の下位に3-bitのzeroを補い、FP16と同じunsigned 11×15の定数乗算器を共有します。
その分を指数依存shiftで調整します。この定数乗算器は近似用の乗算器とは別です。
指数依存shiftでは保持bit・guard・stickyを作り、その後に一度だけRNEします。
最終段は到達する三つのbinadeに絞って正規化し、共通のRNE・FTZ処理で出力します。

## インターフェース

トップは `FP16BF16ExpRecipRsqrtStudy`、入力 `x` と出力 `result` は16 bit、
`op` は3-bit one-hot（001: exp、010: recip、100: rsqrt）です。
無効なopはcanonical qNaNを返します。clock、reset、例外flagはありません。
RTLは `rtl/fp16.sv` 一つです。`is_bf16` は1 bitで、入力の解釈と出力形式を同時に選びます。
形式、op、xは組合せ入力で、各評価時に自由に変更できます。形式間の変換命令ではありません。

## 生成と検証

RTLは上から「入力分解 → expの範囲縮小 → 形式別係数 → 共有一次近似 → 正規化・丸め → 特殊値」の順です。
各段のコメントに固定小数点位置と丸めの意図を記し、係数表は4要素ずつ添字付きで表示します。
回路の読み取りは`rtl/fp16.sv`、係数や生成規則の変更は`gen_rtl.py`を入口にしてください。
生成器も同じ段順で記述し、生成RTLの直接編集は`rtl-check`で検出します。

必要環境はC++17 compiler、binary128対応のlibm、Python 3、NumPy、mpmath、Verilatorです。

```sh
make test
make rtl-check
make rtl-test
```

`gen_rtl.py`は実行時形式切替を持つ一つの一次RTLを生成し、`rtl-check`で再生成一致を確認します。
`study.py`は一次方式専用の整数モデルです。生成物は `build/` に置きます。
`test`は符号付き丸め、全normal値の再pack、FTZ／overflow境界、特殊値、
二形式・三関数の全入力精度と単調性、検査器の異常検出、独立100桁演算との照合を行います。
共有RTLが一つのトップと二つの乗算式だけを持つことも検査します。

`reference.cpp`は近似モデルから独立したbinary128計算を対象形式へ直接RNEします。
FP32やdoubleを中継して出力を丸めません。`rtl-test`は各形式で有効3 op・無効5 opの
全16-bit入力、二形式で計1,048,576組を検査します。各x・opで形式を交互に切り替え、
有効opの出力を各形式の整数モデルとbit一致させます。精度と単調性は形式ごとに検査します。
両形式とも精度違反0、単調性違反0、上記のRTL全数検査通過を確認しています。
これらは全数simulationであり、形式証明ではありません。
