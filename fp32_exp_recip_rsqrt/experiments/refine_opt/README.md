# 一回丸めを基準にする追加最適化

公開トップは変更せず、入出力FTZ、特殊値、無効op、normal結果の最大1 RNE step、
単調性の契約を維持する。strict faithfulは要求しない。

- `centered-single`: expの第2乗算入力からQ18の1を分離し、19 bit積・線形項・C0・
  丸め定数を同じ式へ入れる。既存の`single-round`とのbit一致を要求する。
- `bias-single`: 根系の最後の丸め定数をQ25 C0の1へ織り込む。
  `single-round`とのbit一致を要求する。expの係数とbiasは変更しない。
- `minimax-q24`: 根系C0をQ24とし、隣接行の単調性を制約して最大実数誤差を最小化する。
- `mixed-q24`: 最大実数誤差1.30 ULP以下を条件として、Q25の最下位bitが必要な行数を
  最小化する。Q24候補に加えて元のQ25係数を候補に残す。幅はQ25のままなので、
  行数の削減をそのまま回路面積削減とは扱わない。

根系は全仮数を独立整数参照で検査する。探索用の実数値は出力ULPの2^-20単位へ
厳密整数演算でRNEし、最大誤差に2^-21 ULPを加えた上界も記録する。
RTLとモデルの全仮数比較、全指数境界、exp全入力の公開版とのbit一致を別に確認する。
探索はC0のQ25整数±4、C1/C2の指定した有限近傍であり、最適性はこの候補集合内に限る。

生成・検査は`generate.py`、探索は`search.cpp`、生成物は`../../build/refine-opt/`。
以前の実験と生成物を上書きしない。
