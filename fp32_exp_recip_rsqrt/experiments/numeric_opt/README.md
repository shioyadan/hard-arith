# 係数・丸めと16 bit版の知見を使う追加実験

公開トップは変更せず、同じ入出力FTZ・normal最大1 RNE step・単調性を目標にする。
特殊値、無効op、指数処理は公開版を維持する。strict faithfulは要求しない。

- `signed-round`: exp indexの絶対値丸めと符号反転を一回の加算へまとめる同値変形。
- `single-round`: 根系の第2積の中間丸めを除き、C0を同じ積和へ入れて最後に最近接丸めする。
  tieは正側とする。expは元のbiasを保持し、bit一致を要求する。
- `root-floor`: 根系だけ第2積の中間丸めをfloorへする。最終RNEは残す。
- `c0-q24`: 根系C0をQ24へ再量子化し、C1/C2も局所探索する。expは変更しない。

後三案は数値仕様を保つための候補であり、公開版とのbit同値を前提としない。
根系は全仮数、厳密点、行境界、固定正規化の上下限を検査する。
整数参照による精度検査、RTLとモデルの比較、通常test、候補別合成を区別して記録する。

生成物は `../../build/numeric-opt/`。`generate.py`は公開sourceのhashを固定し、
`screen.cpp`は根系の整数演算と独立した整数参照で候補を選別する。
探索の不成立は指定した探索範囲の結果であり、不可能性の証明ではない。
